
# 🏎️ FURIOUS GARAGE

### Legendary Cars Collection

FURIOUS GARAGE es un sitio web inspirado en los vehículos más icónicos de la saga cinematográfica *Fast & Furious*.

Este proyecto académico presenta un catálogo interactivo de 15 vehículos legendarios, permitiendo a los visitantes explorar sus características, buscar modelos, filtrar resultados, guardar favoritos y realizar simulaciones de compra.

## 🚀 Funcionalidades

- Catálogo de 15 vehículos.
- Fotografías locales de los automóviles.
- Búsqueda de vehículos por nombre, marca o conductor.
- Filtros por película y conductor.
- Sistema de favoritos con LocalStorage.
- Ventana de detalles de cada vehículo.
- Precios ilustrativos en dólares estadounidenses (USD).
- Botón "Comprar ahora".
- Formulario de compra simulada.
- Confirmación de compra con número de pedido.
- Diseño adaptable a dispositivos móviles.

## 🛠️ Tecnologías utilizadas

## 💻 Instalación y ejecución

1. Clona el repositorio:

   git clone https://github.com/USUARIO/FURIOUS-GARAGE.git

2. Abre la carpeta del proyecto en Visual Studio Code.

3. Abre `index.html` en tu navegador o utiliza la extensión Live Server.

No requiere instalación de dependencias mediante npm.

## 🛒 Sistema de compras

El sitio incluye un sistema de compra simulada.

El visitante puede seleccionar un vehículo, introducir su nombre y correo electrónico y confirmar un pedido ficticio.

Al finalizar, el sistema genera un número de pedido.

**Importante:** No se procesan pagos reales ni se envían pedidos a un servidor.
